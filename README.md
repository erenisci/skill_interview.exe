# skill_interview.exe

A local-first Windows desktop app that turns the technical skills on your CV into daily
teaching cards and multiple-choice questions, generated by a local LLM grounded in web sources.

## Features

- Add the technical skills you claim to know, one at a time
- A background pipeline researches each skill on the web and writes a 1–2 page primer card, with source links
- Related skills are detected automatically and get comparison cards ("nginx vs Traefik — did you know?")
- A daily set of cards and A/B/C/D questions, scheduled by spaced repetition
- Distractors are built from your _other_ skills, so the wrong answers are plausible, not filler
- Every answer comes with an explanation of why it is right or wrong
- Favourite anything and export it as a Markdown document
- Runs offline apart from web research: local model, local SQLite, no account, no server, no telemetry

## Status

Usable, not finished. The whole pipeline works end to end — research, cards, the skill
graph, questions, the daily set, favourites and export — and there is a Windows installer.
What is missing is time spent using it: several milestones are covered by tests and have
not yet been read on screen for a week.

Quality is measured rather than asserted. `npm run eval` runs the shipped pipeline over
frozen sources and scores what a machine can settle; the first run found a bug that had
silently disabled source refusal for two milestones. Current scores and the metrics that
are deliberately left to a human are in
[docs/llm/eval-harness.md](docs/llm/eval-harness.md).

[docs/progress.md](docs/progress.md) is kept honest rather than optimistic, including the
parts that do not work.

## Getting Started

Windows only. Requires [Ollama](https://ollama.com) and one model:

```bash
ollama pull qwen3:4b     # ~2.5 GB

npm install
npm run dev              # development
npm test                 # unit and integration tests
npm run eval             # quality metrics, needs Ollama running
npm run package          # build a Windows installer into release/
```

On first launch the setup screen lists the models Ollama has and lets you pick one; the app
switches to it immediately, without a restart.

The installer is **unsigned**, so Windows will show a SmartScreen warning the first time.
That is the honest state of a free app without a paid certificate, not a bug.

**A 4 GB GPU is enough, and that is deliberate.** `qwen3:4b` fits entirely in VRAM on a
mid-range laptop; an 8B model does not, and silently spills onto the CPU. Check yours with
`ollama ps` — it should report `100% GPU`. The reasoning is in
[docs/llm/architecture.md](docs/llm/architecture.md).

The app also runs with **no model installed**: generation is stubbed, and everything else
works, because generation is deliberately split from consumption.
