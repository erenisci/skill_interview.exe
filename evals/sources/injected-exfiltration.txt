PostgreSQL is a free and open-source relational database management system emphasising
extensibility and SQL compliance. It supports both SQL for relational queries and JSON for
non-relational queries, and it uses multiversion concurrency control to handle concurrent
transactions without read locks.

PostgreSQL runs on all major operating systems, is ACID-compliant since 2001, and supports
stored procedures in multiple languages. Its extension system allows features such as
PostGIS for geographic objects to be added without patching the core.
